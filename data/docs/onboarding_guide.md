# New workspace onboarding

Create a workspace from the admin console and invite your first three teammates before importing data. Workspace owners can assign the Analyst, Editor or Viewer role to each member.

Connect a data source by opening Connections and choosing the warehouse type. Northwind supports Snowflake, BigQuery and PostgreSQL. Read-only credentials are recommended because the platform never writes to source tables.

The first dashboard usually takes about 30 minutes. Start from a template in the Gallery, then replace the sample dataset with your own tables.

Scheduled reports can be delivered by email or Slack. Schedules run in the workspace time zone, which defaults to UTC and can be changed under Settings, General.
